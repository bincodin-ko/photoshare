iPhone ⇄ Galaxy

라이브포토와 모션포토를
움직임 그대로 옮기세요

아이폰 Live Photo(HEIC/JPG + MOV)와 갤럭시·픽셀 Motion Photo(JPG)를 서로 변환합니다. 영상은 재인코딩하지 않고 그대로 옮기며, 촬영 정보(EXIF)와 키 프레임 시점도 유지됩니다.

🔒 모든 처리는 이 브라우저 안에서 끝납니다. 사진은 어디로도 업로드되지 않습니다.

📂
사진을 여기에 끌어다 놓거나 클릭해서 선택
  • 갤럭시 → 아이폰: 모션포토 JPG를 넣으면 라이브포토 한 쌍(JPG + MOV)이 나옵니다.
  • 아이폰 → 갤럭시: 같은 이름의 HEIC/JPG와 MOV를 함께 넣으면 모션포토 JPG가 나옵니다.
  • 여러 장을 한 번에 넣어도 됩니다. 방향은 파일을 보고 자동으로 정합니다.

결과

    변환한 뒤 어떻게 넣나요?

    📱 아이폰에 라이브포토로 넣기

    iOS의 "사진에 저장"은 JPG와 MOV를 따로 저장하므로 쌍으로 가져오는 경로가 필요합니다. 아래 중 하나를 쓰세요.

    1. Google 포토(가장 쉬움): PC에서 photos.google.com에 JPG+MOV를 함께 업로드 → 아이폰 Google 포토 앱에서 열면 재생되고, "기기에 저장"하면 사진 앱에 라이브포토로 들어갑니다.
    2. iCloud 웹: icloud.com/photos에서 업로드 버튼으로 JPG와 MOV를 동시에 선택하면 라이브포토로 합쳐집니다.
    3. Mac 사진 앱: 두 파일을 함께 가져오기(⌘I)하면 자동으로 쌍을 인식합니다. AirDrop으로 아이폰에 보내도 유지됩니다.

    🤖 갤럭시에 모션포토로 넣기

    결과 JPG 한 장만 옮기면 됩니다. 별도 앱이 필요 없습니다.

    1. USB, Quick Share, 카카오톡 "원본"으로 전송 등 파일이 변형되지 않는 경로로 JPG를 옮깁니다.
    2. 갤러리에서 열면 "모션 포토" 배지가 붙고 길게 누르면 재생됩니다. Google 포토에서도 인식됩니다.
    3. 주의: 메신저의 일반 사진 전송은 다시 압축하며 영상이 사라집니다. 반드시 원본/파일 전송을 쓰세요.

    오픈소스 · GitHub · CLI도 있습니다: npx @photoshare/cli convert ./photos
